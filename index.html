📖 NEXUS CODEX (MANUAL)
Welcome to Nexus Prime
Nexus Prime is an entirely offline, AST-aware Integrated Development Environment (IDE) built specifically for mobile/PWA environments. Below is a guide to its core functions.
The Kinetic Widgets
🛠 UTIL (Utility Bar)
A floating bar containing common quick actions: Line Jump, Color Picker (injects hex codes), Undo/Redo, and a Tab Injector to fix formatting on mobile keyboards. Dock it to the right side of the screen in the Settings menu.
🔍 FIND & REP (Search Bar)
A draggable search widget. Supports Aa (Case Sensitive), Regex matching, and Global search. Navigate through matches with the Up/Down arrows and tap the REP text to execute a replacement.
✍️ WRITE (Auto-Writer)
Generates filler or mock data. Choose "Syntax" to generate mock code elements, "Story" for Lorem Ipsum text, or "Custom" to use your own array of words (configurable in Settings).
⌨ KEY (Keyboard Monolith)
A custom infinite-scroll coding keyboard designed to bypass mobile keyboard limitations. Click the ✏️ Pencil icon to open the builder and design your own buttons. Use *# to tell the editor where to place your cursor after insertion.
Vortex System (File Management)
📁 VORTEX (Left Panel)
Your Virtual File System. Create, delete, rename, and switch between files here. Files are automatically grouped by extension. Export your whole project as a flat TXT file or a structured ZIP archive. Now supports fast ZIP imports.
🔗 COMBINE FILES
Select multiple files to merge them into a single file. The engine will scan all other files in your Vortex and automatically rewrite their import, src=, and href= paths so they point to the new combined file.
💾 VAULT
A persistent code snippet library. Tap "Cut File" or "Copy File" on the ribbon to immediately send your active file's contents into the vault for later use.
Diagnostics & Testing
🩺 DIAGNOSTICS (Sentinel)
The Sentinel is a static code analyzer (AST). Deep Lint scans for 16+ logic, security, and performance flaws. String Patch fixes minor errors safely. AST Rebuild deconstructs and reconstructs your code to fix structural logic. (Note: In HTML files, Medics will target the first inline script tag).
▶ PROVING GROUNDS (Sandbox)
A live execution environment (Right Panel). It injects your active code into an iframe. It comes with a "Ghost Console" overlay that intercepts console.log() and errors so you can debug directly on your phone. If you are viewing an HTML file, it renders the raw HTML. If viewing JS, it wraps it in a script tag.
Other Utilities
✨ BEAUTIFY
Automatically reformats the current HTML, CSS, or JS file according to your tab-width preference.
🌙 DREAMER
Quickly injects pre-built standard mobile and PWA UI components (like nav bars, modals, lists, or grids) directly into your code.
🌌 SYSTEM GRAPH
A visual, animated node-map of all the files currently inside your Vortex system. Tap a node to warp to that file.
☀️ SUN MODE
Inverts the dark theme to a high-contrast white mode for outdoor coding visibility.
🔗 COMBINE FILES
Select multiple files to merge. All imports across the VFS project will be updated.
