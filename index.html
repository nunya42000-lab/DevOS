📖 divIDE v0.8 — USER GUIDE
MOBILE-NATIVE CODE EDITOR
Built for writing and understanding code on a phone — not a desktop editor squeezed onto a small screen.
1. THE INTERFACE
The Top Ribbon
The main toolbar is a seamless horizontal loop — swipe left/right to reach every button; it wraps around infinitely (an Infinite Scroll toggle for this lives in Settings, off by default). The Edit/Utility Mode button lives first, followed by Save, Undo/Redo, Insert Tab, Outdent, Select All, Cut/Copy/Paste, and Run.
The File Tab Bar
Below the ribbon: a ◀▶ button on the left to show/hide the footer's navigation arrows, a scrollable row of open file tabs in the middle, and a ⋮ dropdown menu button on the far right.
The ⋮ Dropdown Menu
Tap ⋮ at the right edge of the file tab bar for: Edit/Utility Mode, Swap Editor Engine, Light/Dark Mode (toggling this doesn't close the menu, so you can compare both instantly), the display toggles (Indent Guides, Word Wrap, Show Whitespace, Bracket Tracing, Sticky Scope Headers, Minimap, Inline Lint, Autocomplete), the 🧰 Diagnostics Hub, 🔖 Bookmark Line / 📑 All Bookmarks, and Help/Settings.
The 🎮 Navigation Drawer
Tap 🎮 in the footer to open a drawer sliding up from the bottom-left: a diamond of 4 directional arrows on the left for moving the cursor, and 4 fixed action buttons on the right — Jump to Matching Bracket, To 1-Line, Select Lock, and Edit Chunk.
Edit / Utility Mode
One button, two states — tap to flip between them:
  • 🛠️ UTILITY MODE: Full interaction — tap, select, use every tool — but the phone's on-screen keyboard stays hidden, for navigating with the D-pad/toolbar without it popping up.
  • 🔓 FULL EDIT: Standard typing mode. The keyboard activates on tap.
Bracket → Select Lock → Chunk Editor
Place your cursor on a bracket, turn on Select Lock (🎮 drawer, or the footer), then tap Match Bracket — instead of just moving the cursor, this now extends your selection across everything between the two brackets. Tap Edit Chunk next and that exact highlighted range opens in the isolated chunk editor, ready to edit on its own.
Right-Side Panel & Utility Bar Mirror
The right panel's Quick Tools (Mirror) section mirrors the last 6 tools from your utility bar layout, so frequently-used tools are reachable without opening the full utility bar. Customize which tools appear (Settings → Customize Utility Bar).
Editor Shortcuts Bar
The row directly under the ribbon: Undo, Redo, Insert Tab, Fold, Select All, Duplicate Line, Toggle Comment (works in JS/CSS with // or /* */, and in HTML with <!-- --> — auto-detected from the file's extension), Copy/Cut/Paste, Find & Replace, and Run.
2. FILE SYSTEM
Files Panel & Tabs
Files are stored locally in this device's browser database — they persist even if you close the browser, with no account or server needed. Open the 📁 Files panel to see everything loaded into the project. Loaded files sit in this list until you tap one — only then does it open as a tab in the file tab bar. Tapping a tab's × closes just that tab; the file stays loaded and reappears in the Files panel. If a tab has unsaved changes, closing it asks: Cancel, Save & Close, or Close (Discard).
Matrix Operations (Files panel)
High-level, whole-project build commands, in the Files panel:
  • ⚡ BUNDLE: Compiles the entire project (HTML+CSS+JS) into one standalone HTML file.
  • ⚡ MERGE JS: Concatenates all .js files into a single script.
  • ✂️ SPLIT JS: Uses the code's real structure (not just guessing from text) to break one file into several.
  • 🔗 COMBINE: Merges specific files and automatically re-routes every import/src reference to match.
3. DIAGNOSTICS (Command Hub)
Sentinel Lint & Medic
Sentinel runs 14 structural checks — infinite loops, XSS risk, hardcoded secrets, recursion without a base case, unused variables, and more. Tap FIX ALL to auto-apply the ones that have a safe automatic fix.
New: every result now has a "?" button that expands into a plain-English explanation — what it means, why it matters, and how to think about fixing it. Results are also tappable and jump straight to that line in the editor.
HTML / JS / Orphan-ID / CSS Audits
Four focused checks live right below Sentinel in the same Diagnostics section: mismatched HTML tags, JS syntax errors (with a plain-English explanation attached), element IDs nothing references, and CSS selectors matching nothing on the page. All results are tappable and jump to the relevant line.
Night Cycle (Stress Test)
Runs every if-branch in your JS through a background test to catch exceptions that only happen under specific conditions — also in the Diagnostics section, since it's really another way of finding bugs before you do.
Intel (Understand Your Code)
A high-level health score based on file size, security patterns, and structure. Tap the % number to see exactly what was deducted and why.
Project Radar
A visual map of how your files connect. Green = linked and reachable. Red = nothing imports it (dead code).
4. LEARN & FIX
New: a set of tools aimed specifically at fixing things yourself, without needing to ask anyone else.
  • Step Through: Runs your code one meaningful line at a time, showing every variable's live value as it changes — the closest thing to a debugger this app has, built for a screen too small to run one side-by-side with your code. Works on .js files, or .html files with a <script> block. Caps at 500 steps so an infinite loop can't hang the page.
  • Glossary: Plain definitions for common terms (variable, scope, promise, closure, etc.) without leaving the app.
  • Runtime crash explanations: when Run crashes, you now get a translated, plain-English explanation under the raw error, for the mistakes beginners hit most (undefined variables, null references, syntax errors, infinite recursion).
5. MOBILE-SPECIFIC TOOLS
Smart Character Cleanup
Phone keyboards silently turn straight quotes into curly ones and hyphens into em-dashes — both break code, and both are hard to spot by eye. Paste something affected and you'll get a one-tap fix offered automatically; or run Clean Smart Characters (Fix & Format section) on the whole file any time, including catching characters typed with autocorrect on.
6. SNAPSHOTS & VAULT
Snapshots
Tap 📸 in the Files panel to capture your entire project as it is right now (up to the 10 most recent are kept). Tap the 📂 button next to it to browse saved snapshots — each one offers Diff Current File (compares it against the active file in the Merge engine) or Restore Whole Project (replaces every current file with that snapshot's contents; warns first if you have unsaved changes anywhere).
Merge Engine
For complex merges or restoring an older version: a line-by-line diff view where you pick Left, Right, or Both per conflict.
Vault
A persistent snippet library. Select code and tap + GRAB to save it — available from any file, any session.
7. GITHUB SYNC
Settings → GitHub Sync: add a repository (user/repo) and a personal access token (needs "repo" scope), then Push/Pull the current file or Sync Entire Project. The token is stored locally on this device and only ever sent to api.github.com.
TOOLING (CodeMirror 6 Engine)
Three optional CM6 features, all off by default — enable from the ⋮ dropdown menu:
  • 🗺️ Minimap: A compact overview of the whole file for fast spatial navigation on long files.
  • 🩺 Inline Lint: Live inline underlines and gutter markers for issues, powered by the same Sentinel engine behind the Diagnostics Hub — one set of rules, shown two ways.
  • 💡 Autocomplete: Context-aware suggestions and tooltips while typing.
8. TERMINAL COMMANDS
Type into the command slider:
  • ls — list all project files.
  • touch [filename] — create a new file.
  • rm [filename] — delete a file.
  • cat [filename] — print a file's contents.
  • clear — wipe the current editor content.
  • push [filename] [commit message] — push a file to GitHub.
  • pull [filename] — pull a single file from GitHub.
  • pull-all — sync the entire project from GitHub.
  • config set ghToken/ghRepo [value], change-repo [user/repo] — same settings as the GitHub Sync panel, from the terminal.
9. OMNI GESTURE LAYER
3-Finger Gesture Activation
Touch the screen with 3 fingers to draw a gesture:
  • Down → Left: Run Sentinel Deep Lint.
  • Up → Down → Up → Down: Run Intel's health scan.
  • Down → Right → Up → Left: Auto-format the active file.
